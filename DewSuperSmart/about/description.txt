DewSuperSmart adds combat awareness tools for the local hero.

Features:
- Draw basic attack and hero skill ranges.
- Draw enemy casts, live damage/control colliders, projectiles, status-effect auras, and environmental traps.
- Render exact circle, cone, rotated box, line, and polygon boundaries with impact-aware threat colors.
- Continuously avoid active or imminent threats; set a dodge key to make activation hold-to-use instead.
- Optionally reserve one movement-skill charge instead of consuming the last dodge.
- JSON localization is available in the i18n folder.

DewSuperSmart 为本地英雄添加战斗辅助显示。

功能：
- 绘制普攻和英雄技能范围。
- 绘制敌方施法、实时伤害/控制碰撞区、飞弹、状态光环和环境陷阱。
- 精确绘制圆形、扇形、旋转方框、直线和多边形边界，并按命中风险动态变色。
- 持续自动躲避已激活或即将生效的威胁；设置躲避键后可改为按住启用。
- 可选择保留一层位移技能充能，避免自动躲避消耗最后一层闪避。
- i18n 文件夹内提供 JSON 本地化文本。
