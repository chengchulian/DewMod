# 回归检查

在仓库根目录使用 PowerShell 7 运行：

```powershell
.\DewMoreChaosChoices\tests\Run-Regression.ps1
```

依赖已安装游戏及 `ShapeOfDreamsHome`、Visual Studio MSBuild 和 .NET 10 运行时。脚本从 NuGet 下载固定版本的 Harmony 2.4.3 到临时缓存，仅替换测试输出中的运行时依赖。正式 Mod 始终针对游戏自带 Harmony 编译，游戏目录不参与写入。

检查覆盖普通、稀有、史诗、传说品质和堕落混沌五项额外数量的独立性、设为零保留原版及天赋数量、保留其他 Mod 设置的基础数量、奖励池上限、整数溢出、空奖励池、本机游戏两个初始化方法的真实 IL 匹配，以及实际执行补丁后按实例品质选择配置的候选列表递减循环。原版初始化、保存恢复、随机抽取、同步调用和分支标签的结构也会检查；同时确认补丁只挂接服务端生命周期且无客户端玩法界面程序集依赖。

仅房主安装时的实际联机及原版界面布局仍需游戏内验证。
