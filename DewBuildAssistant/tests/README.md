# BD 助手回归测试

从仓库根目录执行 `DewBuildAssistant/tests/verify.ps1`，构建 Release Mod 与控制台回归程序。仅使用 API 替身和当前 `fixtures/build-v5.json`，不启动游戏、不连接 Steam、不修改真实存档。

回归程序报告当前断言数，并校验 15 个 UTF-8 JSON。另检查游戏全部 13 种语言的 81 个翻译字段与格式参数一致。直接链接生产代码验证：

- Version 5 往返、资源 key、中文、大小限制、旧版及不完整结构拒绝、转职标识必填和固定 QWERD 顺序。
- 五个技能位、每技能四个精粹位、空位置、技能与精粹独立核心标记、同技能及跨技能重复精粹拒绝、UI 名称不进入 JSON。
- 当前页／编辑器页选择、其他页与移动记忆保留、预检无副作用、解锁、容量、房间限制、费用、星座相容性和过期计划拦截。
- 中途加入：房间已 InGame、本地仍 InLobby 时入口目标可用，支持当前页和星座编辑页应用；进入对局、观战或未初始化状态后隐藏入口并拦截待提交配装，保持存档和网络状态。
- 转职反射桥的公开接口、独立存档页、扩展技能目录、跨角色星座、普通页保留、模式切换后计划失效，以及普通模式拦截转职标识 Build。
- 候选复制、同技能／跨技能精粹移动与互换、整组技能互换、两端标记保留、交换还原、只有预选精粹的目标、过期来源及无效拖放保留源数据。
- 身份记忆候选仅查看、D 位禁止技能移出或换入；D 位精粹仍可自动放置、同组与跨组互换。
- 本人作品的本地栏位关联：普通／转职隔离、作者校验、错误英雄／无效记录、缺失目录、关联冲突与账号变化，均不猜测当前栏位。
- 图鉴分类：记忆按全部原生稀有度独立分区，英雄／身份分类中的原生英雄及 Q/R 候选顺序，未映射 Mod 记忆保留，稀有度优先于扩展配装目录归属；精粹稀有度与资源 key 排序、搜索空分类隐藏、两级标题语言刷新、移动记忆及排除出池技能过滤。
- 精粹落到技能图标时填入第一个空槽、跨技能移动保留核心标记，同技能／满槽／重复／过期来源／错误类型拒绝时保留源数据。
- 未选择技能时指定放置和自动填充精粹、空技能之间移动、后选技能保留预选精粹、JSON 槽位与核心标记往返、重复精粹拒绝、语言和描述刷新、需求导出。
- 编辑器按当前普通／转职配装页补齐 Q/R/D，保留已有技能、精粹与核心标记；W/E 不自动填充，缺失页和无效记忆索引保留空位。
- 固定 QWERD 模板所用的原生圆框、遮罩和精粹边框解析；必要素材缺失时拒绝创建方框；不使用 Unity 编辑器内置资源。
- 语言回调重复切换、绑定更新、资源显示名刷新、候选名称刷新及语言变化不改变 JSON 内容。
- 应用喊话格式、发送时读取英雄当前翻译、长标题与英雄名长度限制、完整署名、Unicode 字符簇、单行与富文本处理。
- 我的／公开／全部合并、去重、私密草稿与最新可见性优先。
- 工坊上传协程：新建私密作品、更新时保留可见性、提交前保存 ID、失效旧 ID 备份并仅重建一次、新作品失败后保留草稿供重试；网络、权限、元数据错误不触发重建；创建失败保留原关联，错误包含操作阶段与作品 ID。Steam 调用使用预设回调，文件写入独立临时目录。
- 原生图标整体缩放：44px 卡片、偏心及非正方形边界、尚未布局的容器、无效边界和容器尺寸变化。
- 需求消息 Mod 1.5.1 的反射边界替身：加载检测、技能／精粹 key 去重、核心及非核心、默认数值、当前英雄当前页保存、其他英雄和页保留、已有面板与缓存同步、保存失败回滚、空构筑与错误资源拒绝。
- 需求 Mod 重载检测：以当前加载列表和容器为准、忽略驻留旧静态实例、重载后写入新控制器、初始化期间仍显示按钮、缺失控制器时提示错误、容器销毁后隐藏按钮。

CLR 测试使用 MSBuild 自带的签名 Json.NET 13.x，生产 Mod 引用游戏 Json.NET。替身只验证本地调用边界，不模拟 Unity、Steam 或 Mirror 内部实现。实际 QWERD 布局、原生图框与面板、固定头部、按钮居中、拖动手感、入口位置保存、Esc、语言切换时保留表单、转职房主／客户端同步、真实需求 Mod 联动与工坊上传下载需游戏内验证。

固定技能模板的游戏内验收：首次进大厅检查详情、上传预览和技能编辑器；完成一局返回大厅后重复检查，再切换英雄和语言。五个技能圆心应始终在同一行，按键位于圆框上方，四个精粹保持固定弧形；同时检查空技能放精粹、拖动互换和核心边框。
