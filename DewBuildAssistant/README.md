# BD 助手

在大厅浏览、分享和应用《梦之形》的 Build。

- 点击大厅右上角图标打开助手，拖动图标可调整位置。Esc 逐层关闭窗口。
- 列表自动筛选当前英雄，可切换「我的／公开／全部」。点击 Build 查看配装；本人作品显示关联栏位。
- 一键将旅行者记忆、星座和既视感应用到自己当前选择的栏位。请先取消准备；所需内容仍需自行解锁，既视感费用由游戏在开局扣除。
- 应用成功后自动发送「[英雄名]一键星座 Build名称 已应用。 --Bd助手mod」，英雄名跟随游戏语言。

上传与编辑：

- 「上传／更新当前栏位」读取当前配装。在助手中编辑技能构筑，再填写名称和玩法说明。
- 记忆和精粹按游戏稀有度分类，英雄记忆再按角色排列，支持搜索和拖放。
- QWERD 每个位置最多四个精粹；未选技能也可先放精粹，同种精粹在整个构筑中仅保留一份。
- 技能拖到其他技能上时整组互换，包含精粹和核心标记。精粹拖到已有精粹的位置时互换，拖到技能图标时填入第一个空槽。
- 单击已选技能或精粹切换核心标记，右键清空。身份记忆固定，禁止拖动；其下方精粹照常编辑。
- 首次上传为私密作品，可在自动打开的 Steam 作品页面设为公开；之后上传同一英雄、模式和栏位会更新原作品。
- 若原作品已失效并返回 `k_EResultFileNotFound`，上传时会备份旧作品 ID，并自动尝试新建一次私密作品；失败提示包含创建或更新阶段及作品 ID。

可选联动：

- 启用「转职」后可分享与应用转职 Build；普通模式会禁用需要转职的 Build。
- 加载「构筑需求消息」后，可将技能和精粹应用到当前英雄当前栏位的需求列表，再通过该 Mod 发送需求。

支持简体中文、繁体中文、英语、德语、法语、意大利语、西班牙语（墨西哥）、葡萄牙语（巴西）、日语、韩语、波兰语、俄语和土耳其语，跟随游戏语言切换。

使用时保持 Steam 在线。没有本地上传记录的本人作品会显示「未关联栏位」，应用仍使用自己当前选择的栏位。技能构筑供局内搭配参考，技能与精粹仍需在游戏中正常获取。

安装：将发布包解压到游戏的 Mods 目录，在游戏 Mod 管理中启用「BD 助手」。
