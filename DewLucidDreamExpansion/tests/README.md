# 验证

`RegressionHarness.csproj` 链接实际的星座控制器、资源反转控制器和祭坛源码，使用最小游戏桩验证候选筛选、独立选择、重复领奖、恶意索引、距离、房主权限、中途加入、候选耗尽及存档去重，以及资源收入通知、转换重入、余额上限、异常清理。测试桩不验证 Unity 或 Mirror 的运行行为。
额外使用游戏提供的 Harmony 实际安装 BOSS 死亡补丁，验证死亡中断、未开启清醒梦、客户端、重复回调、生成失败重试及生成位置；通过层级桩验证原版 `model` 为空时的完整视觉复制和特效引用重绑定。Unity 渲染与 Mirror 特效消息仍需游戏内验证。
英雄筛选测试覆盖当前英雄专属、其他英雄专属、通用星座及旧选项修复。迷失域使用实际 Harmony 安装窗口和图标补丁，在模拟原生只生成六项、图标只接受六级的条件下验证补齐九项、重复刷新、热加载、逐级解锁和房主选择。
诅咒测试使用实际 Harmony 安装物品生成和商店补丁，覆盖最终生成数值、购买与显示一致、升级合成后重复准备、存档恢复、英雄固有技能、客户端权限及关闭清醒梦。
悔恨之镜测试实际安装迭代器补丁，验证替换物品保留等级与品质、协程等待期间的正常掉落仍受诅咒约束，以及异常后的作用域清理。
本局恢复测试链接实际存档补丁和恢复控制器，覆盖领奖写入持久数据、连续两次 SL、原生恢复成功时保留效果实例、补回缺失清醒梦实体、多人奖励独立恢复、空完成回调、重连、客户端权限、无效存档值及重复回调去重。测试桩通过复制英雄持久字典模拟存档边界；完整游戏序列化、Unity HUD 和 Mirror 同步仍需游戏内验证。

```powershell
./build.ps1 -Project ./DewLucidDreamExpansion/DewLucidDreamExpansion.csproj -Configuration Release
./build.ps1 -Project ./DewLucidDreamExpansion/tests/RegressionHarness.csproj -Configuration Release
& ./DewLucidDreamExpansion/tests/bin/Release/LucidDreamExpansion.RegressionTests.exe
pwsh -File ./DewLucidDreamExpansion/tests/verify.ps1
```

`verify.ps1` 读取编译后的 Harmony 特性，核对已安装游戏程序集的目标方法、注入参数、Mirror 字段、本地化键、打包产物与 UTF-8 编码。
额外核对已安装游戏中悔恨之镜的唯一协程及其记忆、精粹创建入口，以及英雄持久字典、原生星座保存和读档完成回调。
同时检查原生窗口的资源发现入口、六张图标的嵌入字节、透明度、白色像素、边缘留白和独立性。传入 `-InstalledModRoot` 可核对实际安装目录的元数据路径及 DLL 哈希，防止出现只激活空容器的情况。
检查游戏全部13种语言的18个翻译键、非空文本、机制数值和项目引用，以及 Steam 图片的尺寸、引用和预览文件大小。安装检查同时比较全部翻译与宣传图的文件哈希。

`tools/draw-icons.ps1` 使用四倍超采样绘制六张透明 PNG，并输出 `assets/icons-preview.png` 供检查。
`tools/draw-steam-artwork.ps1` 使用现有图标与游戏导出素材合成方形预览、缩略图和横版主图，并检查文字边界；素材来源见 `about/artwork.md`。

## 游戏内验证

1. 两名玩家安装同版 Mod，确认清醒梦窗口按善、混沌、恶分类显示六个新条目，文字及图标完整。
2. 启用天文大师击败领主，确认日志出现“天文大师：已为 … 创建星座奖励祭坛”，祭坛位于领主附近可行走位置，启蒙祭坛光效、三选一图标与数值提示正常，双方可各领一次，后续领主排除已经获得的星座；普通怪物和死亡中断不生成奖励。
3. 祭坛生成后退出并继续游戏，验证选项、已领奖状态与奖励星座恢复；领奖后连续两次 SL，确认六个新增清醒梦中启用项的局内图标恢复、奖励星座等级和强度保留且不重复叠加。让第二名玩家在祭坛生成后加入并生成英雄，确认其选项补齐；双方使用不同英雄，确认各自仅看到当前英雄专属星座与通用星座，重连保留各自奖励。
4. 启用望远镜并切换地图节点，确认只完整揭示图距离两格以内的节点，已访问状态保留，客户端同步一致。
5. 启用资源反转，分别拾取金币、梦尘并出售、分解物品，确认收入等量交换、支出和已有余额遵循原规则。
6. 启用最原始的诅咒，检查本局新掉落、奖励选项和商店购买的记忆初始为1级、精粹初始品质为40%，有区域奖励加成的掉落仍保持该值；刷新商店后显示与购买结果一致。随后正常升级和合成，确认数值可以增长，重新读档后保留增长结果，英雄固有技能与已有物品保持原值。
7. 启用星神的堕落，检查开局和天文大师奖励星座均以50%强度计算，原本减弱的星座保持50%。启用沉足检查闪避实际冷却延长50%。
   启用最原始的诅咒后使用悔恨之镜，确认替换记忆和精粹保留原值加镜子加成；之后再检查普通掉落仍为1级和40%品质。
8. 检查原生迷失域窗口显示1至9级，反复打开及加载 Mod 后条目不重复，7至9级图标显示正确数值。按顺序完成6至9级迷失域，确认新等级解锁、恶清醒梦数量条件、结算深度、继续游戏及9级上限。
